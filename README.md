# Inventory & Sales Management System

A modern inventory, sales, and purchase management platform built to help businesses track stock, monitor sales performance, and manage suppliers and customers — all from a single, clean dashboard.

## ✨ Features

### 📊 Dashboard Overview
Get a complete overview of your business from a single dashboard. Monitor sales, purchases, profits, expenses, payment returns, and low-stock alerts in real time to make informed decisions.

---

### 📈 Sales Analytics
Analyze sales performance through interactive charts and multiple time filters. Gain valuable insights into business trends and monitor overall growth.

---

### 📦 Product Management
Manage your entire product catalog with ease. Add, edit, categorize, and organize products while maintaining accurate pricing, units, and brand information.

---

### 📉 Inventory & Low Stock Monitoring
Keep track of inventory levels and receive instant visibility into products that are running low. This helps prevent stock shortages and improves inventory planning.

---

### 🛒 Purchase Management
Record and manage product purchases from suppliers while automatically updating inventory. Easily maintain purchase history and streamline procurement.

---

### 🔄 Stock Transfer & Adjustment
Transfer products between warehouses or branches and perform stock adjustments whenever necessary. Ensure inventory records remain accurate across all locations.

---

### 🏷 Barcode & QR Code Generation
Generate printable barcodes and QR codes for products to speed up product identification, inventory tracking, and stock management.

---

### 👥 Customer Management
Maintain customer records in one place and keep track of customer activity. The system helps organize customer information for better business management.

---

### 🚚 Supplier Management
Store supplier details and simplify supplier management. Easily manage procurement sources and maintain organized supplier records.

---

### 🎨 Modern & Responsive Interface
Built with a clean, modern, and responsive design that provides a smooth user experience across desktop and tablet devices, making day-to-day operations efficient.

## 🚀 Installation

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/<your-repository>.git
```

### 2. Navigate to the project
```bash
cd <your-project-folder>
```

### 3. Install dependencies
```bash
flutter pub get
```

### 4. Configure the project
Update the API base URL and other required configuration values before running the application.

### 5. Run the application
```bash
flutter run
```
